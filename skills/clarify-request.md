# Уточнение запроса

1. Перед поиском проверь, что в запросе есть: тип вещи, размер, город, бюджет.
2. Нет типа вещи — спроси обязательно: без него искать нечего.
3. Нет размера — спроси, если тип вещи подразумевает размер; иначе предупреди, что ищешь без фильтра по размеру.
4. Нет города — уточни город: поиск на Авито городской.
5. Бюджет не указан — ищи без ценового фильтра, но в выдаче отмечай цену.
6. Не задавай больше 2–3 вопросов за раз; если можно искать с разумными допущениями — ищи и укажи допущения в ответе.
