# Ранжирование и выдача

1. Собери вердикты по критериям пользователя для каждого кандидата.
2. Отсортируй: сначала полностью подходящие, потом частично; среди равных — ниже цена и выше рейтинг продавца.
3. Выдай топ-3–5: для каждого — ссылка, цена, вердикт по критериям, итог по продавцу.
4. Объясни одной фразой, почему отсеяны остальные (цена, размер, состояние, продавец).
5. Ссылки бери только из результатов инструментов, ничего не придумывай.
