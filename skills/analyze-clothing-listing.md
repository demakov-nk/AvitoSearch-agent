# Разбор карточки одежды

1. Вызови avito_item для каждого кандидата (передай id или ссылку объявления).
2. Смотри в порядке: цена → размер → состояние (по описанию и характеристикам) → материал и бренд → дефекты → дата публикации.
3. По каждому критерию пользователя ставь вердикт: «да», «нет», «частично», «не указано».
4. Чего в карточке нет — так и пиши «не указано», не додумывай.
5. Явные признаки дефектов (дыры, пятна, катышки, ремонт) помечай как минус.
6. Если размер не совпадает с нужным — отсеивай сразу.
