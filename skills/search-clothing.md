# Поиск одежды

1. Выдели из запроса: тип вещи, размер, город, цену от/до, пожелания к состоянию.
2. Вызови avito_search: query — тип вещи с ключевыми уточнениями (например, «зимняя куртка женская»), location — город пользователя, priceMin/priceMax — из бюджета.
3. Если результатов мало — ослабь query (убери уточнения, оставь тип вещи); если слишком много — добавь уточнения.
4. Сортируй по свежести (sort=date), для оценки бери первые 5–10 объявлений.
5. Не ищи ничего, кроме одежды: для других категорий — вежливый отказ (см. AGENTS.md).
